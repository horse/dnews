# 日本語版

このディレクトリには、WordPress公開用の日本語原稿を保存する。

- `posts/`: 独立記事。中国語版からの翻訳ではなく、日本語の公的資料と報道を確認して日本語で執筆する。
- `daily/`: 日ごとの総覧記事。
- `edition-YYYY-MM-DD.yml`: 記事数、層、順序、ファイル対応を管理するマニフェスト。

標準のGitHub Actionsは、WordPressへの最終同期状態を `publish` とする。新規記事はAPI上で作成した後、同じ実行内で直ちに公開し、既存記事は `slug` を使って更新する。下書きが必要な場合だけ、手動実行時に `draft` を明示する。

`story_id` と `slug` は中国語版との対応に用い、タイトル、本文、カテゴリー、タグは日本語読者向けに独立して設計する。
