# dnews 扩展日报设计

## 目标

在不删除或降格现有八篇重要新闻的前提下，将 2026 年 7 月 31 日日报扩展为能够同时呈现国家议程、社会结构与日常文化的完整新闻产品。

## 三层结构

### 1. 政治经济大事（core）

保留现有八篇完整报道。它们继续承担全国性政策、经济、安全、灾害和统计议程，不因版面多样性而删减。

### 2. 社会观察（social）

新增八篇独立报道。入选标准不是分类配额，而是新闻能否揭示公共服务、生活条件、家庭与劳动、地方治理、教育文化或长期社会结构。每篇约 500—1,000 字，导语首先交代当天新事实，再解释它折射的社会问题。

### 3. 其他新闻（other）

新增十篇独立报道，覆盖科学、文化、教育、城市、体育、电影与地方记忆。每篇约 300—700 字。篇幅可以较短，但仍必须核验日期、主办者、地点、内容与公共意义，不写成活动宣传或标题摘录。

## 选题与版面原则

- 分类用于组织阅读，不构成硬性配额。
- 每条新闻都必须有 2026 年 7 月 31 日形成的新事实、启动节点、结果或正式活动。
- 同一事件可以有多篇文章，但日报上应组成专题，避免视觉上连续争夺头条。
- `importance` 只负责同层排序：核心 1—8，社会 101—108，其他 201—210。
- 新增 `daily_section` 字段，取值只能为 `core`、`social` 或 `other`。
- 首页继续以八篇核心新闻为主，同时显示少量社会观察和其他新闻入口。

## 数据与发布

每篇文章继续以 Markdown 为唯一底稿，并包含：

- `news_date`
- `daily_section`
- `importance`
- `categories`
- `tags`
- `article_type`
- `analysis_angle`
- `seo_title`
- `meta_description`
- `wordpress` 字段

现有文章只增加 `daily_section: core`，不改变正文、URL、slug、标题和来源。

## 标签规则

延续现有规则：每篇 12—25 个标签；标签必须逐字出现在正文；`wordpress.tags` 与 `tags` 完全一致。标签主要收录人名、地名、组织、制度、作品、设施、行业与有检索价值的概念。

## 页面表现

日报页面依次显示：

1. 今日议程导语；
2. 政治经济大事；
3. 社会观察；
4. 科学、文化、城市与其他；
5. 编辑说明。

三层采用不同视觉密度，但所有条目都链接到独立文章。社会观察以双栏卡片呈现，其他新闻采用更紧凑的卡片网格。

## 验收标准

- 原有八篇文章继续存在且 URL 不变；
- 7 月 31 日共有 8 篇 core、8 篇 social、10 篇 other；
- 三层共 26 篇独立文章；
- 所有文章通过现有标签检查；
- 日报页面显示三个层级并按各自 `importance` 排序；
- 首页仍以核心八篇为首屏，并能看到社会和其他内容入口；
- GitHub Pages 构建成功，公开首页、日报及新增文章返回 HTTP 200；
- WordPress 元数据与 GitHub Pages 数据保持一致。
