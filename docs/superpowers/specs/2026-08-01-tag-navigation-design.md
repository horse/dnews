# dnews 标签展示与导航设计

## 目标

让标签成为 dnews 的公开信息结构，而不只是 WordPress 迁移元数据。标签用于说明一篇新闻涉及的实体与主题，并帮助读者跨文章浏览相关内容。

## 标签口径

每篇新闻保留 12—25 个标签。标签必须在正文中以同样文字实际出现，主要收录：

- 人名、地名、国家与地区；
- 政府机关、国际组织、企业、政党和媒体；
- 法律、制度、政策、统计指标和正式事件名称；
- 对检索有意义的行业、设施、技术及公共议题泛名词。

不收录“问题”“情况”“方面”等缺乏检索价值的普通词。分类继续表示文章所属的大领域，标签表示正文中的具体实体和概念。

## 页面表现

1. 文章页标题下显示主要元数据，正文结尾显示“相关标签”及全部标签。
2. 首页新闻卡片显示前 6 个标签，多余标签以“更多标签”链接收束。
3. 日报页由文章 front matter 动态生成新闻清单，并为每篇显示前 6 个标签。
4. 新增 `/tags/` 标签总页，按标签列出文章数量和相关文章。
5. 顶部导航加入“标签”。

## 数据与发布

标签只保存在文章 front matter 的 `tags` 字段中。GitHub Pages、日报、首页、标签页和未来 WordPress 同步均读取这一份数据，不另建重复清单。

## 验收标准

- GitHub Pages 的 Jekyll 环境能够成功构建站点；
- 首页、日报页与独立文章页都能看到标签胶囊；
- `/tags/` 存在并能列出标签及相关文章；
- 8 篇现有新闻各有 12—25 个标签；
- 每个标签文字都实际出现在对应正文中；
- WordPress front matter 中的标签与公开标签保持一致。
